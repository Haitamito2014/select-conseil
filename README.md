# Site Select Conseil

Site vitrine statique (HTML/CSS/JS, sans dépendance), publié avec GitHub Pages.

- `index.html` : le site
- `assets/img/` : photos, posters vidéo, logo
- `assets/video/` : vidéos (compressées, sans son)

## Formulaire de contact → email
Service FormSubmit.co. Adresse qui reçoit les demandes : dans `index.html`, ligne
`var CONTACT_EMAIL='contact@selectconseil.com';`
À la première demande envoyée depuis le site en ligne, FormSubmit envoie un email d'activation à cette adresse : cliquer une fois sur le lien.
