# Site Select Conseil

Site vitrine statique (HTML/CSS/JS, sans dépendance).

## Mise en ligne sur GitHub Pages
1. Créer un dépôt sur GitHub et y envoyer `index.html` + le dossier `images/`.
2. Settings → Pages → Source : branche `main`, dossier `/ (root)` → Save.
3. Le site est en ligne après 1 à 2 minutes.

## Formulaire de contact → email
- Service : FormSubmit.co (gratuit, sans compte).
- Adresse qui reçoit les demandes : dans `index.html`, ligne `var CONTACT_EMAIL='contact@selectconseil.com';`
- Première demande envoyée depuis le site en ligne : FormSubmit envoie un email d'activation à cette adresse. Cliquer une fois sur le lien ; ensuite chaque demande arrive par email.
